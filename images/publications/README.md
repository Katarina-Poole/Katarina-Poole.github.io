# Publication figures

Each paper on the Publications page shows a figure. To add one, put an image in this folder
named after the paper, with any image extension (`.png`, `.jpg`, `.webp` or `.svg`), e.g.

    images/publications/2026-ferret-regularity.png

It is picked up automatically the next time the site builds. Until then a grey placeholder is shown.

Tips
- Figures display at a 4:3 ratio (about 130 px wide in the list, larger on the Selected cards).
  Crop to one clear panel rather than a whole multi-panel figure.
- Around 800 x 600 px is plenty; keep files under ~200 KB.
- Check the journal's licence before reusing a published figure (CC-BY papers are fine with attribution).
- To use a file with a different name or location, add `thumbnail: /path/to/image.png`
  to the paper's file in `_publications/`.
